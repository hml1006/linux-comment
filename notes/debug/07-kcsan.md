# KCSAN — 数据竞争检测

## 概述

KCSAN (Kernel Concurrency Sanitizer) 是 Linux 内核的数据竞争检测工具，用于检测多线程间的共享数据竞争。KCSAN 通过编译器插桩和运行时检测机制，能够发现并发程序中由于缺少同步保护而导致的数据竞争问题。

## 核心数据结构

### kcsan_ctx

```
struct kcsan_ctx {
    int                      disable_count;       /* 禁用计数器 */
    int                      disable_scoped;      /* 作用域访问禁用计数 */
    int                      atomic_next;         /* 后续原子操作数 */
    int                      atomic_nest_count;   /* 嵌套原子区域计数 */
    bool                     in_flat_atomic;      /* 是否在扁平原子区域 */
    unsigned long            access_mask;         /* 访问掩码 */
    struct list_head         scoped_accesses;     /* 作用域访问列表 */
#ifdef CONFIG_KCSAN_WEAK_MEMORY
    struct kcsan_scoped_access reorder_access;     /* 重排序访问 */
#endif
};
```

## 工作原理

### 采样检测机制

```
┌─────────────────────────────────────────────────────────────────────┐
│                    Sampling Mechanism                          │
│                                                                     │
│  原理: 并非所有内存访问都检测，通过采样减少性能开销                    │
│                                                                     │
│  __kcsan_check_access():                                            │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  1. 检查是否在禁用区域 (disable_count > 0)                   │   │
│  │  2. 检查是否为原子操作 (ATOMIC)                              │   │
│  │  3. 检查是否为 ASSERT 类型访问                               │   │
│  │  4. 采样决定:                                                │   │
│  │     • skip_watch 计数器决定是否跳过                          │   │
│  │     • 默认采样率: 1/(CONFIG_KCSAN_SKIP_WATCH + 1)            │   │
│  │  5. 如果采样命中 → 设置 watchpoint                           │   │
│  │  6. 如果采样未命中 → 检查是否与已有 watchpoint 冲突          │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  采样率配置:                                                         │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  CONFIG_KCSAN_SKIP_WATCH = 1000                              │   │
│  │  → 采样率 ≈ 1/1001 ≈ 0.1%                                   │   │
│  │                                                             │   │
│  │  kcsan.skip_watch=N (运行时可调)                             │   │
│  └─────────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────┘
```

### Watchpoint 设置流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                    Watchpoint Setup Flow                       │
│                                                                     │
│  insert_watchpoint():                                               │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  1. 计算地址槽位 (watchpoint_slot)                          │   │
│  │  2. 尝试在主槽位插入 watchpoint                             │   │
│  │  3. 如果主槽位已满 → 检查相邻槽位                            │   │
│  │  4. 使用 atomic_cmpxchg() 原子插入                          │   │
│  │  5. 如果所有槽位都满 → 返回 NULL (无容量)                    │   │
│  │  6. 插入成功 → 延迟等待 (udelay)                            │   │
│  │     • 任务上下文: kcsan_udelay_task (默认 10 us)            │   │
│  │     • 中断上下文: kcsan_udelay_interrupt (默认 1 us)        │   │
│  │  7. 延迟结束 → 清除 watchpoint                              │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  延迟等待目的:                                                       │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  • 等待其他线程对同一地址的访问                                │   │
│  │  • 如果在延迟期间有其他线程访问 → 检测到竞争                    │   │
│  │  • 如果没有 → 正常继续执行                                     │   │
│  └─────────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────┘
```

### 竞争检测流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                    Race Detection Flow                         │
│                                                                     │
│  find_watchpoint():                                                 │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  1. 计算地址槽位 (watchpoint_slot)                          │   │
│  │  2. 遍历相邻槽位 (NUM_SLOTS = 3)                            │   │
│  │  3. 解码 watchpoint 信息                                    │   │
│  │     • addr_masked, size, is_write                           │   │
│  │  4. 检查访问类型是否匹配                                     │   │
│  │     • expect_write && !is_write → 跳过                      │   │
│  │  5. 检查地址范围是否重叠                                     │   │
│  │     • matching_access()                                     │   │
│  │  6. 如果匹配 → 返回 watchpoint 指针                         │   │
│  │  7. 如果不匹配 → 返回 NULL                                  │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                           │                                         │
│                           ▼                                         │
│  检测到竞争:                                                         │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  1. 收集当前线程的调用栈                                     │   │
│  │  2. 检查 watchpoint 设置者的信息                            │   │
│  │  3. 生成竞争报告                                             │   │
│  │  4. 更新统计计数器                                           │   │
│  └─────────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────┘
```

## 访问类型

| 类型 | 标志 | 说明 |
|------|------|------|
| READ | - | 普通读取 |
| WRITE | `KCSAN_ACCESS_WRITE` | 普通写入 |
| COMPOUND | `KCSAN_ACCESS_COMPOUND` | 复合读写插桩 |
| ATOMIC | `KCSAN_ACCESS_ATOMIC` | 原子操作 |
| ASSERT | `KCSAN_ACCESS_ASSERT` | 断言类型访问 |
| SCOPED | `KCSAN_ACCESS_SCOPED` | 作用域访问 |

## 原子区域

```
┌─────────────────────────────────────────────────────────────────────┐
│                    Atomic Regions                              │
│                                                                     │
│  KCSAN 支持两种原子区域：                                             │
│                                                                     │
│  1. Nestable Atomic Region (可嵌套):                                 │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  • kcsan_nestable_atomic_begin()                           │   │
│  │  • kcsan_nestable_atomic_end()                             │   │
│  │  • 支持嵌套调用                                             │   │
│  │  • 使用 atomic_nest_count 追踪嵌套深度                     │   │
│  │  • 适用于 seqlock writer 临界区                             │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  2. Flat Atomic Region (扁平):                                      │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  • kcsan_flat_atomic_begin()                               │   │
│  │  • kcsan_flat_atomic_end()                                 │   │
│  │  • 不追踪嵌套深度                                           │   │
│  │  • 使用 in_flat_atomic 标志                                 │   │
│  │  • 适用于 seqlock reader 临界区                             │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  独立追踪的原因:                                                     │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  • seqlock writer (nestable) 和 reader (flat) 可能嵌套      │   │
│  │  • 需要独立管理，避免相互影响                                │   │
│  └─────────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────┘
```

### 使用方式

```bash
# 查看统计信息
cat /sys/kernel/debug/kcsan/counters

# 禁用 KCSAN
echo 0 > /sys/kernel/debug/kcsan/enabled

# 启用 KCSAN
echo 1 > /sys/kernel/debug/kcsan/enabled

# 启用弱内存模型检测
echo 1 > /sys/kernel/debug/kcsan/weak_memory
```

## 性能影响

| 方面 | 影响 |
|------|------|
| CPU 开销 | 2-3 倍（取决于采样率） |

## 常见问题

### 误报处理


## 总结

KCSAN 是一个强大的数据竞争检测工具：

1. **编译器插桩**：自动检测内存访问
2. **采样检测**：低开销的运行时检测
3. **原子 watchpoint**：无锁的竞争检测机制
4. **详细报告**：提供完整的竞争上下文
5. **灵活配置**：支持运行时调整参数

KCSAN 是开发和测试阶段发现并发问题的重要工具，但由于性能开销较大，通常不在生产环境启用。
